# MailMind AI

## Overview

MailMind AI is a privacy-focused AI Email Assistant built using n8n and open-source AI models.

The assistant automatically:

- Reads incoming emails
- Classifies email intent
- Generates summaries
- Detects priority
- Creates intelligent reply drafts

All AI processing runs locally using Ollama, ensuring data privacy without relying on paid cloud AI services.

## Tech Stack

- n8n
- Ollama
- Llama 3.2
- Git
- GitHub
